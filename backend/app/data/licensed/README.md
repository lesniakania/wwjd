# Licensed Bible data

Restricted translations are not committed to this repository. A Polish 73-book corpus may be
placed here only after written permission for use in a digital application has been obtained.

The import command requires a private JSON manifest containing at least:

```json
{"translation":"Biblia Tysiąclecia","digital_application_permission":true}
```

Keep the permission document and the corpus outside version control. Apply all attribution,
display, update, and distribution terms from the agreement. Until then production continues to
use the existing 66-book Polish corpus and must not claim full Catholic-canon coverage.
